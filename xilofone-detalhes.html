Explicação

O que esse projeto ensina

  • Como usar a tag audio para reproduzir sons.
  • Como chamar um áudio pelo id usando JavaScript.
  • Como o evento onclick é usado para tocar um som ao clicar.
  • Como o evento keydown escuta o teclado do usuário.
  • Como criar um objeto com a relação entre tecla e nota.
  • Como reiniciar o áudio com currentTime = 0.

        Aqui começa o JavaScript.
        A função document.addEventListener('keydown', ...) escuta o teclado.
    -->
    <script>
        document.addEventListener('keydown', function(event) {
            const tecla = event.key.toLowerCase();

            const notas = {
                'a': 'note1',
                's': 'note2',
                'd': 'note3',
                'f': 'note4',
                'g': 'note5',
                'h': 'note6',
                'j': 'note7'
            };

            if (notas[tecla]) {
                const audio = document.getElementById(notas[tecla]);
                audio.currentTime = 0;
                audio.play();
            }
        });
    </script>
