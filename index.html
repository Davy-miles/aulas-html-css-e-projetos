O que cada coisa faz

Nesse início do estudo web, alguns elementos aparecem com frequência e são essenciais para construir qualquer página.

<html> Define a estrutura principal do documento HTML.
<head> Guarda configurações da página, como título, charset e arquivos externos.
<body> Contém o conteúdo visível da página: textos, imagens, botões e blocos.
<div> Cria blocos ou containers para organizar os elementos da página.
<img> Exibe imagens usando o atributo src, que aponta para o arquivo da imagem.
<audio> Reproduz som em arquivos de áudio como wav, mp3 e outros.
display: flex Ativa o Flexbox, permitindo alinhar elementos em linha ou em coluna.
onclick Executa uma ação quando o usuário clica em um elemento.
addEventListener Escuta eventos do navegador, como clique ou pressionamento de tecla.

Aula 2 Xilofone interativo 
document.addEventListener('keydown', function(event) {
    const tecla = event.key.toLowerCase();
    const notas = {
        'a': 'note1',
        's': 'note2',
        'd': 'note3',
        'f': 'note4',
        'g': 'note5',
        'h': 'note6',
        'j': 'note7'
    };

    if (notas[tecla]) {
        const audio = document.getElementById(notas[tecla]);
        audio.currentTime = 0;
        audio.play();
    }
});
