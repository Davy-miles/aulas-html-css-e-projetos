Explicação

O que esse projeto ensina

  • Criação da estrutura do HTML com html, head e body.
  • Uso de div para criar blocos e organizar o layout.
  • Aplicação de estilos inline e a ideia de container.
  • Uso do display: flex para deixar elementos em linha.
  • Como inserir imagens com a tag img e preencher o espaço.
  • Como a largura, altura e background definem a aparência visual.
Arquivos do projeto 
<!-- index.html -->
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <link rel="stylesheet" href="style.css">
    <title>fluxbox</title>
</head>
<body style="margin: 0; padding: 0; overflow: hidden; display: flex; flex-direction: row; justify-content: center;">
    <div style="width: 45vh; height: 100vh; background-color: #EF767A; display: block;"></div>
    <div style="width: 45vh; height: 100vh; background-color: #456990; display: block;">
        <img src="Goku_29.webp" width="100%" height="100%">
    </div>
</body>
</html>
